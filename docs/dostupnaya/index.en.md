## How to read

- **Russia**: SP 59.13330.2020 (a code of practice, the revised SNiP 35-01-2001). **Serbia**: Pravilnik 22/2015 (as amended 10/2026). **England**: Part M of the Building Regulations and Approved Document M (Vol 1 — dwellings, Vol 2 — other buildings), Approved Document T (toilets). **UAE (Dubai)**: Dubai Building Code 2021, Part C “Accessibility” (a single code for Dubai) and the Dubai Municipality guide (audit checklists); the “Dubai Universal Design Code” itself ⏳ was not read. Abu Dhabi and other emirates ⏳ not included.
- **EU**: there is no single building norm. The European Accessibility Act (EAA) concerns products and services, not buildings. By country: Germany — MBO § 50 (DIN 18040 is paid ⏳), Austria — OIB-RL 4, Spain — CTE DB-SUA, France ⏳.
