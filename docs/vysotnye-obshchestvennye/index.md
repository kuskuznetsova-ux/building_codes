## Как читать

- Общественные здания **до 50 м** (в т. ч. ниже 75 м) — по [7.2](../obshchestvennye/index.md) (СП 118).
- Жилые высотные — [7.4](../vysotnye-zhilye/index.md).
- Для Сербии, ЕС, Англии и ОАЭ проработан только порог высотного здания; остальное — ⏳.
