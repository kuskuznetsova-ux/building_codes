# 7.6.9 Доступность для маломобильных групп

[← К матрице](index.md) · Доступ в здание и квартиры для МГН.

!!! warning "Статус: черновик"
    Цитаты взяты программно из СП 267.1325800.2016 (ред. 30.12.2020) и СП 54.13330.2022 (с изм. 1, 2; сверено с «Гарант» на 24.06.2026, файл пользователя). **СП 477.1325800.2020 заменяется СП 550.1311500.2026: текст СП 550 в портал ещё не загружен ⏳.** Для Сербии, ЕС, Англии и ОАЭ документы ещё не найдены — стоит ⏳ и перечень того, что нужно найти.

=== "🇷🇺 Россия"

    <div class="pair" markdown>
    <div class="orig" markdown>

    *ru · СП 54.13330.2022, п. 4.9:* <small class="actual">актуально на момент публикации 23.10.26</small> 4.9 При проектировании многоквартирного жилого здания должны быть обеспечены условия для доступности МГН: доступность придомовой территории и входной группы здания [площадки крыльца, тамбура, вестибюля, коридора, ведущего к лестничной клетке, лифтового холла (при наличии)] согласно СП 59.13330, требования доступности зданий и территории приведены в СП 136.13330, СП 140.13330.

    </div>
    <div class="ru" markdown>

    *Пояснение:* Должны быть обеспечены условия для доступности МГН: придомовой территории и входной группы (площадки крыльца, тамбура, вестибюля, коридора к лестничной клетке, лифтового холла) по СП 59.13330; требования доступности зданий и территории — СП 136.13330, СП 140.13330.
