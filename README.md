# building_codes

База знаний: сравнение нормативов **Сербии (RS), России (RU), ЕС (EU) и Англии (UK)** по проектированию, архитектуре и пожарной безопасности, а также стадий проектирования и строительства.

Портал собирается MkDocs Material из папки `docs/` и публикуется на GitHub Pages (Settings → Pages → Source: GitHub Actions).

Локально: `pip install mkdocs-material && mkdocs serve`.

Правила оформления — в [docs/contributing.md](docs/contributing.md).
