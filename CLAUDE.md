# Памятка для Claude (передача между сессиями)

Проект: **портал «Строительные нормы RS · RU · EU · UK»** — сравнение норм Сербии, России, ЕС и Англии (стадии проектирования, пожарная безопасность, высотные здания, градостроительство). Сайт: MkDocs Material, публикуется на GitHub Pages (`https://kuskuznetsova-ux.github.io/building_codes/`) workflow'ом `.github/workflows/pages.yml` при пуше в `main`.

## Как общаться и работать (договорённости с пользователем)
- Язык — русский. Про себя говорить в **мужском роде**. Про пользователя без указания пола не гадать.
- **PR открываю сам**, **мерж делает пользователь** (в `main` сам не мержу). После мержа новые правки — в новый PR (перед пушем `git fetch origin main && git merge FETCH_HEAD`).
- Каждая цитата в оригинале слева (чёрным), перевод справа (серым). Не сверенное — помечать **⏳**. Не придумывать ссылки и цифры: цитаты берутся программно из текстов документов (`tools/fire_gen/qlib.py: Q(...)`; если цитата не найдена — генерация падает).
- Серьёзные/необратимые действия (смена видимости репозитория, удаление) — только по просьбе пользователя.

## Структура
- `docs/` — сайт. Генерируемые страницы (не править руками, править генераторы): `docs/stadii/*`, `docs/sravnenie/stadii.md` (матрица), `docs/pozharnaya/*` (кроме `sp1-evakuaciya.md`, `sp4-ogranichenie-rasprostraneniya.md`), `docs/pozharnaya/vysotnye/*`, `docs/gradostroitelstvo/*`, `docs/normy/uk.md`. Руками: `docs/index.md`, `glossary.md`, `istochniki.md`, `contributing.md`, `normy/index.md`.
- `tools/stages_gen/` — генератор стадий (`gen.py`); `tools/fire_gen/` — генератор пожарной безопасности, высотных зданий, градостроительства, Англии (`build.py`, `build_uk.py`; данные: `firedata.py`, `hrdata.py`, `gdata.py`; цитирование: `qlib.py`).
- `mkdocs.yml` — меню (раздел «Пожарная безопасность» перечислен руками — после добавления темы обновить). `site_slugs.py` — латинские якоря вкладок (ru/rs/eu/uk), нужны для ссылок `#ru`.
- Сборка: `python -m mkdocs build --strict` (из корня).

## Как перегенерировать
1. Тексты документов лежат **вне репозитория** (в `tools/src/` или `NORM_SRC=<папка>`; игнорируются). Скачать заново по `tools/SOURCES.md` (имена файлов — как в `FILES` в `tools/fire_gen/qlib.py`).
2. `python tools/fire_gen/build.py` и `python tools/fire_gen/build_uk.py`; для стадий — `python tools/stages_gen/gen.py` (нужны `tools/src/rs`, `st`, `eu`, `uk`).
3. `python -m mkdocs build --strict`, проверить скриншотом (Playwright, chromium из `/opt/pw-browsers`), коммит, пуш, PR.

## Что сделано
Матрица стадий (14 стадий, RU/RS/EU/UK); пожарная безопасность: 14 тем (классы зданий, методики измерения, юридическая сила/СТУ, выходы, расстояния, ширина, огнестойкость, секции, разрывы, фасады, отделка, спринклеры, ДОО и школы, автостоянки); высотные здания (7 тем + таблица порогов); градостроительство (инсоляция, расстояния между зданиями — СанПиН 1.2.3685-21, СП 42.13330.2026); Англия: правовая основа (Building Act, Building Regulations, S.I. 2023/909, gateways), «Нормативы по странам».

## Индексация
Пока сайт в разработке, закрыт от поисковиков: `overrides/main.html` (мета-тег `noindex, nofollow`) + `docs/robots.txt`. Чтобы открыть сайт для поиска — удалить `overrides/main.html`, строку `custom_dir: overrides` в `mkdocs.yml` и `docs/robots.txt`.
